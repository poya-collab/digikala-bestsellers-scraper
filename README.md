# استخراج‌کننده محصولات پرفروش دیجی‌کالا (Digikala Bestsellers Scraper)

این اسکریپت پایتون با استفاده از مرورگر خودکار **Playwright**، فهرست محصولات پرفروش هر دسته‌بندی در دیجی‌کالا را اسکرول و استخراج می‌کند و اطلاعات کامل آن‌ها را در قالب یک فایل اکسل (`CSV`) با پشتیبانی کامل از زبان فارسی ذخیره می‌نماید.

## اطلاعات قابل استخراج برای هر محصول
* رتبه محصول در جدول پرفروش‌ترین‌های آن دسته‌بندی
* کد یکتای کالا در دیجی‌کالا (`DKP`)
* عنوان کامل فارسی محصول
* قیمت فروش نهایی (به تومان)
* قیمت اصلی قبل از تخفیف (به تومان)
* درصد تخفیف
* جزئیات و برچسب‌های روی کارت (ارسال فوری، فروش ویژه، امتیاز و...)
* لینک مستقیم صفحه محصول

---

## پیش‌نیازها و نصب (ویژه سیستم‌عامل ویندوز)

### ۱. نصب پایتون
1. وارد سایت [python.org](https://www.python.org) شوید و از بخش **Downloads** آخرین نسخه پایتون را دانلود و اجرا کنید.
2. در صفحه اول نصب، تیک گزینه **Add python.exe to PATH** را فعال کنید و روی **Install Now** بزنید.
3. در صورت باز شدن پنجره پیکربندی پایتون در خط فرمان، برای تایید محدودیت طول مسیر (`Update setting now?`) و اضافه شدن به مسیر سیستم (`Add commands directory to your PATH now?`) حرف `y` را وارد کرده و کلید **Enter** را بزنید.

### ۲. آماده‌سازی پوشه و نصب کتابخانه‌ها
1. یک پوشه جدید (مثلاً با نام `digikala`) بسازید و فایل `run.py` را از همین مخزن دانلود کرده و داخل آن قرار دهید.
2. وارد پوشه شوید، روی نوار آدرس بالای پنجره کلیک کنید، عبارت `cmd` را تایپ کرده و **Enter** بزنید تا پنجره خط فرمان در همان مسیر باز شود.
3. دستور زیر را در خط فرمان اجرا کنید تا ابزارهای مورد نیاز نصب شوند:

```bash
pip install pandas playwright

```

*(نکته: این کد به‌صورت پیش‌فرض از مرورگر **Google Chrome** نصب‌شده روی ویندوز استفاده می‌کند و نیازی به دانلود مرورگر جداگانه ندارد. اگر از مرورگر Microsoft Edge استفاده می‌کنید، در کد فایل `run.py` عبارت `channel="chrome"` را به `channel="msedge"` تغییر دهید.)*

## نحوه اجرا و استفاده

1. فایل `run.py` را با یک ویرایشگر متن (مانند Notepad) باز کنید.
2. در ابتدای کد، مقدار متغیر `category` را به کد انگلیسی دسته‌بندی مورد نظر تغییر دهید و تعداد خروجی دلخواه را در `target_count` مشخص کنید:

```python
category = "perfume-all"  # کد دسته‌بندی در آدرس دیجی‌کالا
target_count = 200        # تعداد محصولی که می‌خواهید استخراج شود

```

### روش پیدا کردن کد دسته‌بندی (`category`):

وارد دسته‌بندی مورد نظر در سایت دیجی‌کالا شوید و مرتب‌سازی را روی «پرفروش‌ترین» بگذارید. عبارت انگلیسی بعد از `/search/category-` در نوار آدرس مرورگر، کد دسته‌بندی شماست:

* مثال ۱: در آدرس `https://www.digikala.com/search/category-beauty/?sort=7` کد دسته‌بندی برابر با `beauty` است.
* مثال ۲: در آدرس `https://www.digikala.com/search/category-personal-care/?sort=7` کد دسته‌بندی برابر با `personal-care` است.

3. فایل `run.py` را ذخیره (`Ctrl + S`) کنید.
4. **فیلترشکن یا پروکسی را خاموش کنید** (دیجی‌کالا درخواست‌های IP غیرایرانی را مسدود می‌کند).
5. در پنجره CMD دستور زیر را اجرا کنید:

```bash
python run.py

```

6. مرورگر گوگل کروم به‌صورت خودکار باز می‌شود، صفحه را اسکرول می‌کند و پس از رسیدن به تعداد محصول تعیین‌شده بسته می‌شود. فایل اکسل خروجی (مثلاً `top_200_perfume-all.csv`) در کنار فایل کد ذخیره خواهد شد.
